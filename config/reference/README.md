# Contratos de referência operacionais

Este diretório preserva os contratos tabulares usados pelos QCs e ETLs enquanto
a modelagem transversal é consolidada.

Fontes de verdade conceituais:

- chaves transversais: `catalog/keys.tsv`;
- relacionamentos transversais: `catalog/relationships.tsv`;
- semântica por sistema: `systems/<sistema>/`.

Os arquivos abaixo mantêm granularidade operacional útil para scripts e registram
a evidência empírica das validações. Não devem divergir dos catálogos canônicos.
